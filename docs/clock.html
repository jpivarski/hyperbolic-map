One-handed clock

This clock only has—and only needs—one hand. The 12 hours, 720 minutes, and 43,200 seconds are all marked on the clock face with plenty of room for their labels. You just need to scroll out to them to find them.

How this is drawn

The tick marks and labels on the clock face are all static drawables. The clock's hand is defined dynamically and updated every second.

See the code in docs/clock.html.
