hyperbolic-map

An interactive viewer for vector maps of the hyperbolic plane, drawn in the Poincaré disk. Scroll and rotate it like a map, except that the space it shows has more room in it than any flat map could — every step outward reveals exponentially more.

Zero dependencies, plain JavaScript. See the README for the API and MATH.md for the geometry.

Examples

  • Hyperbolic clock

    Every second of twelve hours on one face, because there is always more room further out.

  • Compass mode

    Holding a bearing fixed while scrolling, versus letting the curvature turn you.

  • Circle Limit III

    One exact tile of fish on a true {8,3} tiling, repeated forever.

  • Dungeon Man

    A prototype room in every cell, characters overlaid, numbers generated on the fly.

What this is

It is a revival. The original was a 2011–2012 experiment pairing a Java servlet with a browser client, written up in a blog post called Lost in Hyperbolia; the server and the blog are long gone. The client has been rewritten from scratch as a modern library, the example data recovered from the original database files, and the mathematics re-derived and checked — which turned up a handful of real errors in the original, documented in MATH.md.
